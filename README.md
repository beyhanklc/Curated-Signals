# Curated Signals

**Thoughtfully crafted audio tools. Freely shared.**

A curated collection of free, open-source audio plugins built with **JUCE & HISE**.

Created with a focus on sound quality, practical functionality, and thoughtful design. Each plugin is an independent project, developed to be useful, accessible, and easy to explore.

### What's Inside

A growing collection of audio effects and utilities for music production, mixing, and sound design.

### Open Source

All projects are freely available under their respective GNU licenses. Explore the source code, learn, modify, and contribute.

### Built With

- **JUCE** — Cross-platform audio application framework.
- **HISE** — Open-source framework for audio plugin development.
